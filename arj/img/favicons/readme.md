# Website icons (favicons)

ARJ's own two, shown beside links to them by `arj/js/link-icons.js`. Every deck made with ARJ links to reveal.js and to its source on GitHub, so these two belong here. Any other website's icon belongs to the deck that links to it: the deck keeps the icon in its own folder and names the site in `linkIcons: { folder, sites }` (the demo does this for Wikipedia, in `demo/img/favicons/`). The icons belong to their websites and are used only to mark links to them.
