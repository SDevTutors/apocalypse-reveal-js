About this demo

  • Every slide shows one thing ARJ adds to reveal.js
  • Getting around: → for the next topic, ↓ for the slides in it. The contents button, bottom left, opens the contents; type a number and press Enter to jump to it
  • Top right: the padlock, the pen, blackout, all slides, full screen and exit
  • Version 1.8.15 is year.tenth.change: the year (1 is 2026), which tenth of the year (0 to 9), and one more for every change in that tenth, from 1

Links

  • A website's own icon before each link. ARJ brings two, reveal.js and GitHub; a deck adds its own in its CSS, like Wikipedia here (a[href*="wikipedia.org"]::before)
  • Links to other websites open in a new tab (linkIcons: { newTab: true }), marked with an arrow out of a box, so the slides stay open
  • A site without its own icon gets a plain link icon: jsDelivr
  • A file on GitHub shows its type, in the code font: readme.md, index.html, arj.css, deck.js, version.py; a folder, arj/img/
  • Links to slides in the deck stay in this tab: the code box

The padlock

  • Locked: the mouse changes slides (left click on, right click back, the wheel one slide), and text can't be selected
  • Unlocked: select and copy text; the mouse stays on this slide
  • Links, buttons and copy icons work either way

A stack of slides

The grey bars under the heading are the slides in this stack; the gold one is this slide. Click a bar to go to its slide.

A code box

The copy icon at the top right copies the code; it turns into a tick.

Drawing

  • Press the pen at the top right, or D. Draw, then press the pen again, or Esc
  • The tools are at the top (drawToolbar: 'top'), clear of the slide number
  • Only the slide can be drawn on: the rest goes grey, with a gold line round the slide
  • Drawings stay with their slide until the page is reloaded
  • A double click selects a word; it doesn't start drawing (drawOnDoubleClick: false)

Search

  • Press the magnifying glass at the top right, or Ctrl+F: it searches every slide, not just this one
  • It searches as you type and counts the finds: "3 of 12"
  • Enter or Down goes to the next find, on whichever slide it's on; Shift+Enter or Up to the one before
  • The slide list shows each line with a find; click one to go to it
  • Esc closes it. Try it: search for "draw"
